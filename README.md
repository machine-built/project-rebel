**Project Rebel**  
Early alpha of an **AlmaLinux 10 Atomic** respin with native  **KDE Plasma**, aiming to be a lightweight, enterprise-friendly RHEL 10 desktop replacement.  
*NOTE: Alpha build. Codename "Project Rebel." Expect breakage and missing docs. Not for production.*  
**What It Is**  
Built on AlmaLinux's Atomic SIG bootc base (image-based, atomic updates instead of RPM layering), same model used by atomic-desktop and other AlmaLinux-based atomic respins like stillOS and HeliumOS [web:2][web:4][web:10]. RHEL/AlmaLinux normally only offers KDE via EPEL, not natively, this image bakes Plasma in directly [web:12].  
**Goals**  
Proof of concept for open source enterprise atomic desktop deployment.  
**Install**  
*Distributed as rebase from atomic fedora or other fedora based atomic distro.*

Bug reports welcome, especially on Plasma integration and desktop responsiveness.
